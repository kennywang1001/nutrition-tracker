# 運動紀錄 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 使用者記下運動（活動、分鐘、時間），後端用 MET × 那天或之前最新的體重 × 小時估算消耗（沒有體重就手動輸入）；今天的熱量額度可以加回運動消耗（設定，預設開），總覽與飲食頁用額度當分母；總覽時間線與飲食頁看得到運動，可改可刪；可匯出。

**Architecture:** 一張新表 `exercise_entries` ＋ `users.exercise_adds_to_budget`（migration `0020`）。活動清單與公式是 `app/exercise.py` 的純函式（Decimal、HALF_UP 到整數）；讀資料庫的小函式在 `app/exercise_data.py`（估算、某一天的合計），「某一天或之前最新的體重」是 `app/body_data.py` 的 `weight_as_of`。端點在 `app/api/routes/exercises.py`（兩個 router：`/api/exercise/...` 給活動清單與預覽、`/api/exercises` 給 CRUD）。`/api/stats/daily` 多三個欄位；設定經 `PATCH /api/me`。前端：`api/exercises.ts`、共用表單 `ExerciseForm`、兩個畫面、時間線第三種列、飲食頁卡片、每日目標卡片的開關。

**Tech Stack:** FastAPI · SQLAlchemy 2 async · Alembic · PostgreSQL 16 · React 19 · TypeScript strict · TanStack Query v5 · react-router · CSS Modules · lucide-react · Vitest · Playwright · Biome

**依據規格：** `docs/superpowers/specs/2026-10-14-exercise-design.md`（以下稱「規格」；D1…D28 指它的 §2）

## 開工前必讀

1. 「Expected: FAIL」沒有如預期失敗 → 停下來回報。新模組還不存在時紅的是 import，不是斷言——斷言有沒有咬合力由每個 task 的突變步驟證明（handover §6 規矩 1、8）。
2. 引用的程式碼對不上現況 → 以現況為準並回報。
3. **「今天」與「現在」一律 monkeypatch，而且記下收到的時區**：`app.api.routes.exercises.today_in_timezone`、`app.api.routes.exercises.utc_now`（Task 2 新增的接縫）。測試使用者的時區設成 `America/New_York`（不是預設的 Asia/Taipei），傳錯時區才測得出來。`app.api.routes.stats` 沒有被 monkeypatch 的「今天」——那邊的測試一律帶 `?date=`。
4. `client` 夾具跟測試共用一個 session、外層一個交易（handover §6 第 14 種）：`now()` 整條測試是同一個值，**`updated_at` 有沒有變在端點測試裡看不到**——不要寫那種斷言。
5. 共用 session 裡 `rollback()` 之後 ORM 物件會過期：id 先存成區域變數。要測「資料庫擋下來」用 `async with db_session.begin_nested():` 包 raw SQL，**並斷言錯誤訊息裡是哪一個約束的名字**（第 13 種）。
6. 端點在 `await db.commit()` 之後不碰 ORM 物件；**回應在 commit 之前組好**（身體資料審查 M6，D21）。
7. **「看不到」的測試先在同一條測試裡看得到一次**（A 自己讀得到、B 讀不到）。只斷言 404 的測試，路徑打錯也會綠。
8. 前端的 `tests/helpers/mock-api.ts` 用 `url.includes(path)` **依序**比對：`/api/exercises` 會吃掉 `/api/exercises/7`；`/api/exercise` 會吃掉 `/api/exercise/activities` **也會吃掉** `/api/exercises`。**更具體的排前面**；路由字串一律寫完整（`/api/exercise/activities`、`/api/exercise/estimate`、`/api/exercises/7`、`/api/exercises`），不要寫 `/api/exercise` 這種前綴。
9. 會畫出總覽或飲食頁的既有測試都會多打 `GET /api/exercises`——沒有準備路由，`mockApi` 會丟「測試沒有為這個路徑準備回應」。Task 5 建 `tests/helpers/exercise-routes.ts`，Task 7 逐檔加上。
10. 前端**不算今天**、不算日界線；數字運算只在 `lib/decimal.ts`（`decimal.js` 只准在那裡 import）。日期與時間欄位用 `lib/dates.ts` 的 `localDateTime`／`fromLocalDateTime`（裝置時區，同 `EditMeal`）。
11. 離線快取裡的舊資料可能少了新欄位（`undefined`，不是 `null`）：`stats.kcal_budget`、`me.exercise_adds_to_budget` 一律經過 Task 5 的小函式讀。
12. Playwright 的名稱一律 `exact: true`；登入之後**只用點擊換頁**；等頁面獨有的元素再動作；只量有界的一組元素的觸控高度（dev 資料庫有 900 多個帳號，不要量清單）。

"""運動紀錄（運動規格 §5）。只有自己看得到：好友與社群的模組連這幾個名字都不准出現
（`tests/test_exercise_privacy.py` 掃的是文字）。"""

from datetime import datetime
from decimal import Decimal

from sqlalchemy import (

    CheckConstraint,
    DateTime,
    Enum,
    ForeignKey,
    Identity,
    Index,
    Integer,
    Numeric,

# CHECK 的文字從列舉產生，模型跟清單不會不同步；migration 裡是寫死的字面值（migration 不 import app）。
_ACTIVITY_CODES_SQL = ", ".join(f"'{code.value}'" for code in ActivityCode)


class ExerciseEntry(Base):
    __tablename__ = "exercise_entries"
    __table_args__ = (
        # name= 是命名慣例的輸入：最後是 ck_exercise_entries_<name>（handover §7）。
        # 列舉欄位用 create_constraint=False，這兩條手寫的 CHECK 是它們唯一的約束。
        CheckConstraint(f"activity IN ({_ACTIVITY_CODES_SQL})", name="activity_valid"),

        # D4：「其他」⇔ 有名稱；「其他」一定是手動的熱量。

        CheckConstraint("activity <> 'other' OR kcal_source = 'manual'", name="other_is_manual"),
        CheckConstraint("char_length(name) BETWEEN 1 AND 50", name="name_length"),
        CheckConstraint("minutes BETWEEN 1 AND 600", name="minutes_range"),
        CheckConstraint("kcal BETWEEN 1 AND 5000", name="kcal_range"),
        CheckConstraint("char_length(note) <= 200", name="note_length"),
        Index("ix_exercise_entries_user_id_performed_at", "user_id", "performed_at"),
    )

    id: Mapped[int] = mapped_column(BigInteger, Identity(always=True), primary_key=True)
    user_id: Mapped[int] = mapped_column(
        BigInteger, ForeignKey("users.id", ondelete="CASCADE"), nullable=False

    activity: Mapped[ActivityCode] = mapped_column(

            create_constraint=False,

    name: Mapped[str | None] = mapped_column(Text)
    minutes: Mapped[int] = mapped_column(Integer, nullable=False)
    kcal: Mapped[Decimal] = mapped_column(Numeric(7, 2), nullable=False)
    kcal_source: Mapped[KcalSource] = mapped_column(

            name="exercise_kcal_source",
            native_enum=False,
            create_constraint=False,
            length=16,
            values_callable=lambda e: [m.value for m in e],
        ),
        nullable=False,

    note: Mapped[str | None] = mapped_column(Text)
    created_at: Mapped[datetime] = mapped_column(

def local_day(instant: datetime, tz_name: str) -> date:
    """這個時刻在使用者時區是哪一天（跟 `day_bounds` 同一個時區庫）。"""

async def estimate_for(
    db: AsyncSession,
    *,
    user_id: int,
    tz_name: str,
    activity: ActivityCode,
    minutes: int,
    performed_at: datetime,
